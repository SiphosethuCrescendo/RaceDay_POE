# RaceDay - Event Management System for South African Road Events

## 📋 System Overview

RaceDay is a comprehensive event management platform designed specifically for the South African road running, walking, and cycling community. The system enables Event Organisers to create and manage events, categories, and participant results, while Participants can browse upcoming events, register, and track their performance history.

## 👥 User Roles

### 
- Create, edit, and delete events
- Manage event categories (distance, fee, capacity)
- Capture and upload participant results
- View all event enrolments and participant details
- Update enrolment statuses (Registered → Confirmed → Completed)

### Participant
- Create an account and manage profile
- Browse upcoming events with filtering options
- Enrol in events by selecting a category
- View personal enrolment history
- Track personal results and performance
